# BMIダイエットアプリ：目標減量計算

あなたはダイエットアプリの計算ロジックを担当しています。
ユーザーの現在の「身長」「体重」と、目標とする「BMI値」が与えられるので、目標を達成するために最低何kg減量する必要があるかを算出してください。

### BMIの計算式

$$BMI = \frac{体重(kg)}{身長(m)^2}$$
※身長の単位は **メートル(m)** であることに注意してください。

### 目標体重の考え方

目標体重 $W_{target}$ は、目標BMIを $T$ 、身長(m)を $M$ とすると以下の式で求められます。
$$W_{target} = T \times M^2$$

### 入力される値

入力は以下の3行で与えられます。

1.  現在の体重 $W$ (kg)
2.  現在の身長 $H$ (cm)
3.  目標とするBMI値 $T$

### 期待する出力

目標BMI以下になるために減量すべき重量を **正の整数** で出力してください。

  - 小数点以下の計算が発生する場合、**小数第1位を切り上げて整数**にしてください。
  - すでに目標BMI以下の場合は `0` を出力してください。
  - 末尾に改行を入れ、余計な文字、空行を含んではいけません。

### 条件

  - $10 \le W \le 200$
  - $50 \le H \le 250$
  - $10 \le T \le 40$
  - 入力はすべて数値（整数または小数）として与えられます。

-----

### 入力例1

```
100.0
180.0
22.0
```

### 出力例1

```
29
```

（解説）

1.  身長 180cm = 1.8m
2.  目標体重 = $22.0 \times (1.8^2) = 22.0 \times 3.24 = 71.28$ kg
3.  必要減量 = $100.0 - 71.28 = 28.72$ kg
4.  小数第1位を切り上げて `29` と出力

### 入力例2

```
60
160
25
```

### 出力例2

```
0
```

（解説）
現在のBMIは $60 / (1.6^2) \fallingdotseq 23.4$ です。すでに目標の 25 以下なので、減量の必要はありません。

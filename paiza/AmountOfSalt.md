あなたは健康のために食事の塩分の量を知りたくなりました。



食事の量 x グラム、塩分濃度 y パーセントが改行区切りで与えられるので何グラムの塩分が含まれるか出力してください。



### 入力例 1 の場合
```
500

2
```
以下のように出力してください。
```
10
```


評価ポイント

10回のテストケースで、正答率、実行速度、メモリ消費量をはかり得点が決まります。

より早い回答時間で提出したほうが得点が高くなります。複数のテストケースで正しい出力がされるか評価（+50点）

解答までの速さ評価（+50点）

入力される値

### 入力は以下のフォーマットで与えられます。
```
x

y
```
・1 行目に食事の量 x グラムが与えられます。

・2 行目に塩分濃度 y パーセントが与えられます。

・入力は合計で 2 行となり、末尾に改行が 1 つ入ります。



それぞれの値は文字列で標準入力から渡されます。標準入力からの値取得方法はこちらをご確認ください

### 期待する出力

食事の量 x グラム、塩分濃度 y パーセントが改行区切りで与えられるので何グラムの塩分が含まれるか整数で出力してください。



末尾に改行を入れ、余計な文字、空行を含んではいけません。

条件

### すべてのテストケースにおいて、以下の条件をみたします。
```
・100 ≦ x ≦ 2000

・0 ≦ y ≦ 10

・x は 100 の倍数
```
### 入力例1
```
500

2
```
### 出力例1
```
10
```
### 入力例2
```
100

0
```
### 出力例2
```
0
```
